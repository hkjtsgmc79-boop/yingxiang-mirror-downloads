API REFERENCE

接口说明

页面目录由 GitHub Pages 提供；下列任务接口在下载后的本机服务中运行。

接入接口及运行环境
方法路径用途运行环境
GET./catalog.json读取公开目录当前网页
GET/v1/health查看服务状态本机服务
GET/v1/templates查询可用模板本机服务
POST/v1/tasks创建固定参考任务本机服务
GET/v1/tasks/{task_id}查询任务状态本机服务
GET/v1/results/{task_id}.svg取得固定参考结果本机服务
